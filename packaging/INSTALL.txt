Scroll native installation (Omarchy x86_64 or ARM64; Arch Linux or Arch Linux ARM)

Prefer the pacman package:
  sudo pacman -U scroll-*.pkg.tar.zst

For the manual binary tarball, install system runtime dependencies:
  sudo pacman -S --needed qt6-base
For native Wayland support:
  sudo pacman -S --needed qt6-wayland

From the extracted binary tarball directory:
  sudo install -Dm755 usr/bin/scroll /usr/bin/scroll
  sudo install -Dm644 usr/share/applications/scroll.desktop /usr/share/applications/scroll.desktop
  sudo install -Dm644 usr/share/icons/hicolor/scalable/apps/scroll.svg /usr/share/icons/hicolor/scalable/apps/scroll.svg
  sudo install -Dm644 usr/share/icons/hicolor/512x512/apps/scroll.png /usr/share/icons/hicolor/512x512/apps/scroll.png
  sudo install -Dm644 usr/share/licenses/scroll/LICENSE /usr/share/licenses/scroll/LICENSE
  sudo update-desktop-database /usr/share/applications
  sudo gtk-update-icon-cache -f -t /usr/share/icons/hicolor

Run scroll as your normal desktop user. These binaries use Arch's system Qt
libraries; they are not standalone or intended for other distributions.
Do not mix manual installation with a pacman-managed installation.

Choose Scroll using your file manager's Open With settings if desired. If an
association pointed to qOmaedit, select Scroll again after upgrading.

A development symlink at ~/.local/bin/scroll takes precedence over /usr/bin
when ~/.local/bin appears first in PATH. A user launcher with the same desktop
ID also takes precedence over the packaged launcher. Keep these if you want to
run your local development build; remove them yourself when switching to the
packaged version. Scroll saves user preferences in ~/.config/Scroll.
